# 四川农业大学27个本科教学学院与院徽

核验与补充日期：2026年10月2日。按用户要求，清单、网页与总览仅保留27个本科教学学院。

## 数量依据

以[教务处2026级培养方案](https://jiaowu.sicau.edu.cn/web/web/lanmu/jihua_new.asp?jh_nj=2026)为准：91条培养方案记录，学院去重后27项；成都14个、雅安10个、都江堰3个。已直接访问核验，原始记录见 teaching-plan-2026-snapshot.json。首页导航目前链接2025级，2026参数页面公开可访问且有实际记录；页面沿用“2025年10月8日更新”字样，不以该字段作为2026数据更新时间证据。

[学校简介](https://www.sicau.edu.cn/xxgk/xxjj.htm)称29个学院（文中数据截至2026年6月），[学校教学科研导航](https://www.sicau.edu.cn/jgsz/j_x_k_y_d_w/cdxq.htm)列有31个名称含学院的单位；这些与本科教学名单口径不同，本清单统一采用教务处27个本科教学学院的范围。

## 院徽与预览

27个本科教学学院中，23个在官网找到了独立学院标识；用户补充经济学院、信息工程学院两张院徽后，可展示25个。两张用户图片已与学院官网新闻中实际使用的院徽设计核对一致；文件来源仍单独标记为用户附件，不改写为官网直接提供的独立素材。原始PNG完整内嵌在 assets/ 下的SVG容器中，未重绘，经济学院图片保留用户原图已有的截边。

农业工程学院、土木工程学院当前官网使用校徽或校徽与院名组合，本次尚未确认独立院徽。清单保留两所学院，图像预览的对应位置留空，不使用校徽替代院徽。

“独立学院标识”包括圆形院徽和其他形状的学院LOGO。原始官网素材保持原貌；预览通过CSS视窗仅展示院徽区域，移除横版素材中院徽外的校名、学院名称。院徽内部原有文字和图案保留，不重新绘制。

院徽预览及PNG按学院清单相同顺序，以6列排列27个位置，其中25个显示院徽、2个留空。每个位置下方显示对应学院名称，院徽内部文字和图案保留。院徽与名称由同一条学院记录生成，避免错配。

已重新读取27个学院的官网页面、核对23张官网标识及2张用户院徽，并检查总览中实际显示的图案。逐项依据与例外见 [logo-audit.md](logo-audit.md)。
