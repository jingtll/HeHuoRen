# 学生端样式 Demo

这些 HTML 用于比较页面布局、配色、字体和组件风格，直接用浏览器打开即可，不依赖外部字体或图片服务。

| 文件                                                                  | 定位                                         | 当前用途                 |
| --------------------------------------------------------------------- | -------------------------------------------- | ------------------------ |
| [hehuoren-student-demo.html](hehuoren-student-demo.html#competitions) | 第一版，暖白与禾苗绿，桌面侧栏、移动底部导航 | **选定的学生端视觉基准** |
| [style-01-natural.html](style-01-natural.html)                        | 清新自然校园风，浅绿插画与圆角卡片           | 静态备选参考             |
| [style-02-notebook.html](style-02-notebook.html)                      | 青春手帐风，奶油黄、便签拼贴与纸张纹理       | 静态备选参考             |
| [style-03-editorial.html](style-03-editorial.html)                    | 极简编辑风，留白、细线与列表排版             | 静态备选参考             |

第一版涵盖比赛发现、招募、申请邀请、我的队伍、收藏、通知、个人资料和样式规范，交互仅在浏览器模拟。改动保存在该 Demo 的独立 localStorage 项中，可在个人资料或侧栏重置；不创建真实账号、不提交真实报名、不向服务器发送申请或举报。

后三份为静态风格对比，分类、筛选和状态仅展示外观，导航链接跳转至同一页面的分区。全部比赛、队伍、人物、学院范围和截止时间为演示内容，不能当作报名通知或学校完整名录。

开发应用中的共享主题已提取到 [apps/web/src/style.css](../../apps/web/src/style.css)。后续 Vue 页面遵循[学生端全局样式](../student-ui-style.md)，Demo 本身不等于已实现业务路由或服务端功能。
