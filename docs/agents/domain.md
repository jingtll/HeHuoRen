# 领域文档

## 探索前阅读

- 阅读根目录 `CONTEXT.md`；若存在 `CONTEXT-MAP.md`，则按映射阅读相关上下文。
- 阅读 `docs/adr/` 中与当前工作相关的决策记录。
- 缺少这些文件时继续工作，不因缺失要求提前补齐；由 domain-modeling 在术语或决策明确时按需创建。

## 布局

本仓库采用单一上下文：

- `CONTEXT.md`：领域词汇表。
- `docs/adr/`：系统级架构决策记录。

## 术语与决策

- 输出、issue 标题与测试名称中的领域术语遵循 `CONTEXT.md`。
- 新术语尚未进入词汇表时，先判断是否确有领域概念缺口，再补充。
- 发现实现与 ADR 冲突时，明确指出冲突及重新讨论的理由。
