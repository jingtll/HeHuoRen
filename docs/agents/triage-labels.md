# 分诊标签

Matt Pocock 工程技能使用以下角色；操作 GitHub Issues 时使用表中对应的标签。

| 技能中的角色      | GitHub 标签       | 含义                      |
| ----------------- | ----------------- | ------------------------- |
| `needs-triage`    | `needs-triage`    | 维护者需要评估问题        |
| `needs-info`      | `needs-info`      | 等待报告者补充信息        |
| `ready-for-agent` | `ready-for-agent` | 需求明确，可由 Agent 实施 |
| `ready-for-human` | `ready-for-human` | 需要人工判断或实施        |
| `wontfix`         | `wontfix`         | 决定不处理                |

类别标签使用 `bug`（已有行为出错）或 `enhancement`（新增或改进行为）。完成分诊的问题保留一个类别标签和一个状态标签；状态标签互相冲突时先与维护者确认。

生成已确认的方案或拆分出可实施任务时使用 `ready-for-agent`。后续更换标签名称时修改此表，其他文档通过引用使用此映射。
